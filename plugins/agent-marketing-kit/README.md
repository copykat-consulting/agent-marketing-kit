# CopyKat Agent Marketing Kit

Marketing tools for real estate agents, from CopyKat Consulting.

## Skills

- **Marketing Command Center**: a private dashboard for your monthly marketing. A content checklist with draft and go-live dates, a review and approval workflow for you and your assistant, Instagram, Facebook, LinkedIn and Google Business performance from Metricool, a visual content ideas board and a 12-month year plan. Start it by telling Claude: "Set up my Marketing Command Center."

## Install

In Claude: **Customize → Plugins → Add → Add marketplace → Add from a repository**, enter `copykat-consulting/agent-marketing-kit`, then add **CopyKat Agent Marketing Kit**.

In Claude Code:

    /plugin install agent-marketing-kit --marketplace copykat-consulting/agent-marketing-kit

# Brand Brain Template

Use these ten headed sections, in this order. Write in the agent's first person for headers and framing ("Who I Am," "My Voice"). Use their own words wherever possible. Replace every bracket. If something is missing, write `MISSING:` and name it. Never fill the gap.

## 2. Who I Serve
**Primary focus going forward:** one to three client groups. Note if this is a deliberate shift from the historical mix.

For each group:

- Their real concerns, in the agent's words (what they ask or worry about in the first conversation)

**Still served, but not the growth focus:** groups the agent works with but is not trying to grow.

**How clients find me:** referrals, website, social, events, word of mouth, whatever the agent named.

Plain language. No slogans, no taglines. Describe the real positioning: how the business was built, what the agent can do that most competitors cannot, and why clients return or refer. Use specifics from the agent's answers and reviews.
